CODE SCARPER TARGET EXTRACTOR v6.0.0
توسعه‌دهنده: Reza Zarnegar

راهنمای سریع:
1) یک صفحه HTTP/HTTPS را باز کنید.
2) روی آیکون افزونه کلیک کنید.
3) Click = انتخاب یک Target
4) Ctrl + Click = اضافه/حذف چند Target
5) Extract Selected = دانلود فایل JSON کامل

میانبرها:
Alt + ↑ = انتخاب والد
Alt + ↓ = انتخاب اولین فرزند قابل مشاهده
Esc = خروج از Picker

فایل logo.png در روت پروژه قرار دارد و به عنوان آیکون افزونه در manifest.json استفاده می‌شود.
برای توضیحات کامل README.md یا README_FA.md را ببینید.
